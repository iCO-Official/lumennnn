## Lumen — твой ежедневник нового поколения

Предлагаю название **Lumen** (от лат. "свет") — короткое, премиальное, легко запоминается. Лого: тонкий круг с точкой внутри (символ дня/осознанности), монохром — белый на чёрном / чёрный на белом в зависимости от темы.

## Что войдёт в v1

### 1. Лендинг (публичная страница `/`)
- Hero с анимированным заголовком, кнопки **Войти** / **Регистрация** справа сверху
- Секции: возможности (планирование, сон, здоровье, AI-анализ), как работает, призыв установить как PWA на iPhone
- Плавные анимации (Motion), минимализм в духе Linear / Notion / Things
- Тёмная тема по умолчанию, переключатель темы

### 2. Аутентификация (`/auth`)
- Email + пароль
- **Войти через Google** (через Lovable Cloud)
- **Войти через Apple** (через Lovable Cloud)
- При регистрации — выбор темы (тёмная/светлая)

### 3. Личный кабинет (`/app`)
- **Планировщик** — задачи на день / неделю / месяц с переключением вкладок
- **Тренировки** — отдельный раздел для плана тренировок
- **Дневник мыслей** — текстовое поле "что я думал сегодня"
- **Сон** — время отхода/подъёма, качество (1–5)
- **Здоровье** — настроение, энергия, вода, шаги
- **Статистика** — графики выполнения задач, сна, настроения за неделю/месяц
- **AI-инсайты** — кнопка "Проанализировать неделю" → Lovable AI читает данные и даёт советы

### 4. PWA
- Манифест + иконки → "Добавить на экран Домой" на iPhone работает как приложение

### 5. Дизайн-система
- OKLCH токены, чёрный фон `oklch(0.13 0 0)`, акцент — тёплый белый
- Шрифт: Inter (UI) + Instrument Serif (заголовки для премиальности)
- Лого SVG, инвертируется по теме

## Технические детали
- Stack: TanStack Start + Supabase (Lovable Cloud) + Lovable AI Gateway (`google/gemini-3-flash-preview`)
- Таблицы: `profiles`, `tasks`, `workouts`, `journal_entries`, `sleep_logs`, `health_logs`
- RLS: каждый юзер видит только свои данные
- AI-анализ — server function, читает данные юзера, возвращает советы

## Объём
Это большой проект. Предлагаю в этом ходе сделать:
1. Дизайн-систему + лого + лендинг с анимациями + переключение тем
2. Страницу `/auth` с Google/Apple/Email
3. Базовый каркас `/app` с планировщиком задач

Дневник, сон, здоровье, статистика и AI добавим следующими итерациями — иначе получится поверхностно везде.
